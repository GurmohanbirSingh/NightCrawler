# Security & Responsible Use

NightCrawler is intended for authorized security assessment and security research in controlled environments.

Only run the scanner against systems you own or systems for which you have explicit permission to perform the listed tests. Do not use it to bypass access controls, disrupt services, or access data without authorization.

Never commit `.env`, API keys, credentials, session cookies, production scan output, or other secrets. Review the repository contents before publishing.

Findings produced by the scanner should be manually verified before being treated as confirmed vulnerabilities.
